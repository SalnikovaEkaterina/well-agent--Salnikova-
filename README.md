# AI-агент для анализа работы нефтяных скважин

## 1. Описание проекта

Проект разрабатывается в рамках курса **Agents: Deep Dive**.

Цель проекта — создание AI-агента для автоматизации инженерных расчётов, анализа работы нефтяных скважин и прогнозирования добычи.

Агент будет принимать запросы пользователя на естественном языке, определять необходимый инструмент, выполнять расчёты и формировать ответ с численными результатами и единицами измерения.

## 2. Задачи AI-агента

- Получение параметров скважины через MCP-сервер WellLab.
- Расчёт рабочей точки скважины методом узлового анализа (IPR/VLP).
- Расчёт дебита скважины по корреляции Вогеля.
- Прогнозирование снижения дебита по экспоненциальной модели Арпса.
- Анализ результатов расчётов и формирование инженерных пояснений.
- Проверка исходных данных и обработка ошибок.

## 3. Используемые технологии

- **Python** — реализация расчётных инструментов и логики агента.
- **OpenAI API** — обработка запросов на естественном языке и выбор инструментов.
- **MCP (Model Context Protocol)** — взаимодействие с инженерным симулятором WellLab.
- **Pydantic** — валидация входных и выходных данных.
- **Pytest** — тестирование функций.
- **GitHub** — совместная разработка и хранение проекта.

## 4. Инженерные инструменты

### IPR Vogel

Функция `ipr_vogel()` предназначена для расчёта дебита нефтяной скважины по корреляции Вогеля.

Входные данные:
- Пластовое давление, атм.
- Забойное давление испытания, атм.
- Дебит испытания, м³/сут.
- Заданное забойное давление, атм.

Результат: расчётный дебит скважины, м³/сут.

### Arps Decline

Функция `arps_decline()` используется для прогнозирования дебита по экспоненциальной модели снижения добычи.

Входные данные:
- Начальный дебит, м³/сут.
- Годовой коэффициент спада.
- Период прогнозирования, годы.

Результат: прогнозный дебит, м³/сут.

### MCP WellLab

Планируется использование инструментов MCP-сервера для получения информации о скважинах, расчёта IPR/VLP, определения рабочей точки и построения прогноза добычи.

## 6. Принцип работы агента

1. Пользователь отправляет инженерный запрос.
2. Языковая модель анализирует запрос и выбирает подходящий инструмент.
3. Агент передаёт параметры расчёта локальной Python-функции или MCP-серверу.
4. Инструмент выполняет расчёт и возвращает результат.
5. Агент проверяет результат и формирует ответ с единицами измерения и пояснениями.

## 7. Ожидаемые результаты проекта

В результате разработки планируется получить AI-агента, который сможет:

- Выполнять инженерные расчёты по запросу пользователя.
- Использовать инструменты MCP-сервера.
- Определять рабочие параметры нефтяных скважин.
- Прогнозировать изменение дебита.
- Предоставлять обоснованные ответы на основе результатов инструментов.
